orca orchestration ask

Usage: orca orchestration ask (--question <text> | --resume <message_id>) [--to <run:id>] [--run <run_id>] [--options <csv>] [--wait] [--timeout-ms <n>] [--from <handle>] [--retry-request <id>] [--json] [--full]

Ask the coordinator a question; Orca wakes you with the answer

Options:
  --help                 Show this help message
  --json                 Emit machine-readable JSON
  --pairing-code <code>  Run against a remote Orca server using an orca://pair?... code
  --environment <selector> Run against a saved paired Orca server (id or name), or `local` for this machine's own Orca over ORCA_ENVIRONMENT/ORCA_PAIRING_CODE; terminal handles belong to the server that issued them
  --to
  --run
  --question
  --resume
  --dispatch-capability
  --options
  --wait
  --timeout-ms <ms>     Maximum wait time before timing out
  --from
  --retry-request <id>  Reissue an earlier request by its ID; replays its result instead of repeating it
  --full                 Print the full record Orca returned instead of the concise view

Notes:
  From a worker, a new question goes to its coordinator and ask returns at once: end your turn, and Orca wakes you with the answer as mail. A worker that already finished waits for the answer instead. --wait and --resume block until the answer instead; --timeout-ms accepts 1 to 1800000 ms per wait (default 600000 = 10 minutes, max 30 minutes), and a timeout leaves the question pending.
